# Resume project description

## GitContext — AI-powered GitHub repository assistant

**Technologies:** Python, FastAPI, React, TypeScript, Qdrant, Sentence
Transformers, BM25, Gemini, Docker Compose

Built a repository question-answering application that ingests public GitHub
codebases and returns conversational, source-grounded answers. Implemented
semantic and BM25 hybrid retrieval with reciprocal-rank fusion, cross-encoder
reranking, and linked file-and-line citations. Delivered a responsive React
chat UI with repository-specific conversation history, plus Docker Compose
deployment with persistent vector data and model caching.

### Short resume bullets

- Built a full-stack GitHub codebase assistant using FastAPI, React/TypeScript,
  hybrid vector/keyword retrieval, reranking, and Gemini.
- Added conversation-aware follow-ups and answers linked to repository source
  files and line ranges.
- Containerized the application with Docker Compose, Nginx API routing,
  health checks, and persistent Qdrant/model-cache volumes.
